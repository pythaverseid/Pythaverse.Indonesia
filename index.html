LMS Pythaverse

Satu platform belajar dari Pythaverse Indonesia. Di dalamnya ada dua perangkat lunak: editor untuk membuat program, dan digital twin untuk menjalankan serta melihat hasilnya secara visual.

Software editorBlockly Editor dan Leanbot IDE untuk menyusun blok dan menulis kode. Digital twinRobot dan arena virtual 3D untuk menguji program dan belajar digital visualisasi.

Software editor

Siswa bisa memulai dari blok, lalu naik ke kode.

EDITOR 1

Blockly Editor

Program disusun dari blok. Kategori Logic, Loops, Math, Variables, Functions, Arduino, dan Leanbot tersedia di sisi kiri.

Kode Arduino di sebelah kanan ikut berubah, jadi siswa melihat hubungan antara blok dan kode.

EDITOR 2

Leanbot IDE

Editor kode berbasis web dengan menu Libraries, Tools, PTutor, dan Serial. Papan Arduino UNO dipilih langsung dari IDE.

Digital twin

Kembaran digital dari robot dan arena.

SIMULASI

Belajar digital visualisasi

Program dijalankan pada robot virtual di arena 3D. Waktu dan skor misi tampil langsung, sehingga siswa bisa menguji dan memperbaiki programnya.

Siswa mengamati gerak robot dan membaca hasilnya lewat visual, tanpa harus menunggu giliran memakai robot fisik.

Sekolahmu mau jadi mitra Leanbot berikutnya?

Garis putus-putus menggambarkan jaringan kerja sama dari pusat (Jakarta). Peta bersifat skematis (bentuk pulau disederhanakan). Titik ditempatkan di tingkat kabupaten/kota. Sekolah yang lokasinya belum jelas ditampilkan di bagian bawah daftar.
